# Public deployment - Sierra Leone AgriMarket Intelligence Platform

This version is prepared for public internet access so group members and lecturers can open the system from different networks.

## Recommended hosting

The project is configured for Render using one public Django web service and a managed PostgreSQL database. Render's current Django deployment guidance supports PostgreSQL, WhiteNoise, a build script, and a `render.yaml` Blueprint. The service uses the public web URL generated by Render.

## What you need to do

1. Create a GitHub account if you do not already have one.
2. Create a new GitHub repository, for example `sierra-leone-agrimarket`.
3. Upload the **contents** of this project folder to that repository. Do not upload the `.venv` folder or `db.sqlite3` if they exist.
4. Create/sign in to a Render account and connect GitHub.
5. In Render, create a **New Blueprint Instance** and select the GitHub repository.
6. Render will read `render.yaml`, create the web service and PostgreSQL database, install the Python and frontend dependencies, build the React interface, run Django migrations, load demo data, and start the public site.
7. After deployment finishes, Render will show a public `.onrender.com` address. Send that address to your group members and lecturer.

## Important

- The local `start_backend.bat` and `start_frontend.bat` are still available for development on your laptop.
- Public deployment is separate from your home/office Wi-Fi. Other people can use the public Render address from their own internet connections.
- The demo administrator is `admin / admin123`. Change this before treating the public site as a real production system.
- This academic prototype currently uses permissive API permissions (`AllowAny`). For a real public production system, authentication and role permissions should be tightened before collecting sensitive data.
